Современный адаптивный сайт для компьютерного клуба **BOOTCAMP** (г. Петропавловск, Казахстан).


## 🚀 Как запустить сайт

### Через XAMPP
1. Установите [XAMPP](https://www.apachefriends.org/).
2. Скопируйте папку `bootcamp-site` в `C:\xampp\htdocs\`.
3. Запустите Apache в панели управления XAMPP.
4. Откройте: `http://localhost/bootcamp-site/`

### Через хостинг
1. Загрузите содержимое папки `bootcamp-site` на хостинг в `public_html/`.
2. Сайт доступен по вашему домену.

## 🛠️ Как изменить данные

### Цены
В файле `index.html` найдите раздел `#tariffs` и измените значения в `.tariff-row`.

### Характеристики компьютеров
В файле `js/script.js` отредактируйте массив `COMPUTERS_DATA`.

### Статусы компьютеров

Для ручного изменения: в `js/script.js` найдите функцию `initDemoData()`.

### Изображения
Замените файлы в папке `images/` на свои. Рекомендуемые размеры:
- `hero-bg.jpg` — 1920×1080
- `club-1.jpg`, `club-2.jpg`, `club-3.jpg` — ~800×600
- `logo.png` — ~200×50, прозрачный фон
- `favicon.png` — 32×32

### Карта
В `index.html` замените `iframe` в разделе `#contacts` на реальную карту через [Яндекс.Карты](https://yandex.ru/map-constructor), [2GIS](https://2gis.ru) или Google Maps.

## 🗄️ Подключение backend

Для реальной работы необходимо:
1. Создать базу данных (MySQL/PostgreSQL)
2. Создать API-эндпоинты (PHP/Node.js)
3. Заменить `localStorage` на `fetch()`-запросы в `js/script.js`

Рекомендуемые таблицы:
- `computers` — данные ПК и статусы
- `bookings` — заявки на просмотр игровых мест
- `admins` — администраторы
